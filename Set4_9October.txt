Q2 : Write a PL/SQL block using IF–ELSIF–ELSE to assign a grade based on marks.
•  DECLARE a variable marks and assign a value. 
•  Use IF marks>=90 THEN 'A', ELSIF marks>=75 THEN 'B', ELSIF marks>=50 THEN 'C', ELSE 'F'. 
•  Test the block with at least 3 different boundary values (e.g., 95, 76, 40).

code:

        DECLARE
            marks NUMBER := &marks;
        BEGIN
            IF (marks >= 90) THEN
                DBMS_OUTPUT.PUT_LINE('You have achieved Grade : A');
            ELSIF (marks >= 75) THEN
                DBMS_OUTPUT.PUT_LINE('You have achieved Grade : B');
            ELSIF (marks >= 50) THEN
                DBMS_OUTPUT.PUT_LINE('You have achieved Grade : C');
            ELSE 
                DBMS_OUTPUT.PUT_LINE('You have failed in this exam. Your grade is : F');
            END IF;
        END;

Q3 Write a PL/SQL block using a loop construct to generate the first 10 terms of the Fibonacci series.

•  Initialize the first two terms (0 and 1). 
•  Use a WHILE LOOP or FOR LOOP to compute and print the next 8 terms. 
•  Print all 10 terms using DBMS_OUTPUT.PUT_LINE.

code :

        DECLARE
            FTerm NUMBER := 0;
            STerm NUMBER := 1;
            NewTerm NUMBER;  
            uLimit NUMBER := &numberOfTermsYouWant;
        BEGIN
            DBMS_OUTPUT.PUT('Fibonacci series of ' || uLimit || ' term is : ' || FTerm || ' ' || STerm || ' ');
            
            FOR i IN 3..uLimit LOOP
                NewTerm := FTerm + STerm;
                FTerm := STerm;
                STerm := NewTerm;

                DBMS_OUTPUT.PUT(NewTerm || ' ' || ' ');
            END LOOP;
            DBMS_OUTPUT.PUT_LINE('');
        END;
        /
